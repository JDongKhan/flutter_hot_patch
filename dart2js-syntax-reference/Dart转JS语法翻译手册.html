00实现总则

七条硬约束，违反即视为未完成；后续各章均为其展开。

原则硬约束
类型注解擦除，泛型实参随尾参下发类型标注不进产物；构造与方法的尾参对象必须携带 typeArguments（__ta，已有具名参数时复用 __o），运行时靠它完成 T == X、as T、provider 键控。
空安全无运行时表示，但有可观察行为! / ?. / ?[] / ?? 的改写必须保住三件事：接收者只求值一次、null 时短路、表达式返回值正确。
成员翻译只有三种合法写法① 同名直译；② JS 同名但语义不同 → _ 前缀 + 构建期映射表（主键 = 接收者内建类型 + 成员名，如 (List, sort) → _sort）；③ JS 缺同名 → 运行时在具体内建原型补同名。映射只在接收者静态类型可判定时生效，绝不按方法名全局替换；禁止挂 Object.prototype，补齐统一 Object.defineProperty + enumerable:false + 存在性守卫。
Dart 只有 null，JS 有 null 与 undefined宽空模型：凡可能产出 undefined 的位置（Map 未命中、数组越界、可选链短路、缺省实参），判空与取用前先用 __nn 归一（undefined → null，不抛错），再用 == null（禁止 === null），合并用 ??。只对可能为空的操作数包：非空类型 / 字面量 / 构造不包。
编译期概念靠展开，不靠运行时特性mixin、extension、运算符重载、枚举都是编译期展开；判据只来自源码事实（类表、extends / with 链、import 归属、显式类型注解与项目类构造推断），不做名字猜测、不维护类型白名单。
产物形态与命名必须手册登记产物里每个非 Dart 名字（包装函数、类名、成员名、前缀、临时对象）都必须是本手册登记过的；未登记先补手册 + 开发确认。禁止 __map(...)、__Map、{__proto__: Map.prototype} 等形态；索引改写只允许登记表项（List / 项目类 / 不可判定保持原生 a[i]）。
产物可验证，且手册先行每条规则能构造「null 分支 / 非 null 分支 / 求值次数」三个断言；改规则同步更新对应行、CHANGELOG 与示例。手册未更新视为未完成，禁止「先实现再解释」。

01翻译流水

名字解析必须早于代码生成，空安全改写必须晚于类型信息收集。

阶段项目现状
解析Dart AST，保留源位置供报错与生成映射。
类型与流分析不做：parseString，无 analyzer resolution / 流分析 / 类型提升；静态类型只来自显式注解与项目类构造推断，未知即不参与改写。
名字解析类表 + 静态类型：实例字段 / 方法按类表（含 extends 链），extension 按源码归属；不做 import 顺序 / show-hide 冲突解析（冲突项构建期告警）。
节点改写空安全赋值、?? 括号、mixin 展开、extension 调用重写、枚举 / record 结构替换。
代码生成ES2020 输出，括号按目标语言优先级重建。
自检求值次数、短路、返回值三类断言。
依赖以 JS 产物为准 Dart 的 import / 类型引用只是候选依赖；只有该引用真的进入产物（目标类 / 顶层常量 / 顶层函数被发射且调用点被翻译）才形成依赖。JS 侧依赖链断开时不得为 Dart 依赖强行发射目标文件（如 main.dart / app_log_console.dart 不进入补丁）。
引擎能力边界（硬约束） 产物运行在 Android QuickJS 2021-03-27（flutter_js 0.8.7）与 iOS 15+ JavaScriptCore，基线为 ES2020 + 部分 ES2021（??= / ||= / &&=、Promise.any、AggregateError、String.replaceAll）。禁止使用两端未实现的 API：Object.hasOwn、at、findLast / findLastIndex、class static block、top-level await、structuredClone、WeakRef / FinalizationRegistry。需要同等能力时在运行时补同名实现或改用 ES2020 写法。

JS · 唯一改写形态（IIFE）

// 语句位置：接收者只求值一次，null 时整句跳过
((__t) => { if (__t != null) __t[i] = v; })(recv);

// 值位置：守卫内 return 赋值结果，目标为空返回 null
((__t) => { if (__t == null) return null; return (__t[i] = v); })(recv);

// 链式赋值：前缀单次求值 + 一层守卫，深度只让前缀变长
((__t) => { if (__t != null) __t.c = v; })(a?.b);
判空用 != null，不要用 !== null 可选链短路得到的是 undefined；__nn(a?.[i]) 归一回 null 后再比较，下游只看到 null。IIFE 只适用于语句位置，值位置必须补 return；传入的必须是源码里真正的赋值目标。

05集合类型

List / Map / Set 与 JS 的方法名、参数顺序、越界行为与惰性差异；同名成员按接收者类型分派。

List → Array
