# UI Component 组件支持文档

> 本文档列出 `hot_patch_generator`（生成器）当前支持的 Flutter 组件、属性与写法约束。
> 生成器把 `@PatchEntry` 注解类（含 `build()` 树）翻译为 JS 产物；`hot_patch` 运行时把产物还原为真实 Flutter widget（原生 vs JS 热更共用同一套属性协议）。
>
> **对齐口径**：生成器侧 `packages/hot_patch_generator/lib/src/translator/builtin_translators.dart` + `style_translators.dart`；运行时侧 `packages/hot_patch/lib/src/json/flutter_from_json.dart` + `js_ui/js_widget_registry.dart`。两端对称，新增属性必须同时改两侧。

---

## 1. 组件支持矩阵

### 1.1 布局类

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **Column** / **Row** | `children`、`mainAxisSize`、`mainAxisAlignment`、`crossAxisAlignment` | 主轴枚举：`MainAxisSize.min/max`；`MainAxisAlignment.start/center/end/spaceBetween/spaceAround/spaceEvenly`；`CrossAxisAlignment.start/center/end/stretch/baseline` |
| **Expanded** / **Flexible** | `flex`、`child` | 仅用于 Row/Column 内；`flex` 需整数字面量 |
| **Spacer** | `flex` | Row/Column 内弹性空隙；`flex` 需整数字面量（默认 1） |
| **Center** | `child` | 单子 |
| **Padding** | `padding`、`child` | `padding` 支持 `EdgeInsets.all/symmetric/only/fromLTRB`，见 §3.1 |
| **Align** | `alignment`、`child` | `alignment` 支持 `Alignment.center/topLeft/topCenter/topRight/centerLeft/centerRight/bottomLeft/bottomCenter/bottomRight` |
| **Stack** | `children`、`alignment`、`fit`、`clipBehavior` | `fit` 支持 `StackFit.loose/expand/passthrough`；`clipBehavior` 见 §3.5 |
| **IndexedStack** | `index`、`children`、`alignment` | 只显示 `index` 指定的单子；`index` 支持状态字段表达式 |
| **Positioned** | `left`、`top`、`right`、`bottom`、`width`、`height`、`child` | 仅用于 Stack 内；数值需字面量；支持 `Positioned.fill(...)`（四边默认全 0 撑满，显式参数可覆盖偏移） |
| **SizedBox** | `width`、`height`、`child` | 可带 child（如 `SizedBox(height:100, child: Stack(...))`） |
| **Wrap** | `children`、`spacing`、`runSpacing`、`direction`、`alignment`、`runAlignment`、`crossAxisAlignment` | `spacing`/`runSpacing` 需数字字面量；`direction` 为 `Axis.*`；`alignment`/`runAlignment` 为 `WrapAlignment.*`；`crossAxisAlignment` 为 `WrapCrossAlignment.*` |
| **SafeArea** | `child`、`left`、`top`、`right`、`bottom` | 四边开关为 bool 字面量（默认 true） |
| **Opacity** | `opacity`、`child` | `opacity` 需数字字面量 |
| **ConstrainedBox** | `constraints`、`child` | `constraints` 见 §3.6 BoxConstraints |
| **AspectRatio** | `aspectRatio`、`child` | `aspectRatio` 需数字字面量 |
| **FractionallySizedBox** | `widthFactor`、`heightFactor`、`alignment`、`child` | 因子需数字字面量 |
| **SingleChildScrollView** | `child`、`scrollDirection`、`padding`、`physics`、`reverse`、`controller` | `scrollDirection` 支持 `Axis.horizontal/vertical`；`physics` 见 §3.7；`controller` 透传 JS ScrollController 句柄 |
| **ListView** | `children`、`scrollDirection`、`padding`、`shrinkWrap`、`physics`、`itemExtent`、`controller` | 列表子项走通用翻译（含 for 循环展开）；`shrinkWrap` 未下发时运行时按 true 处理（兼容旧产物）；`ListView.builder` / `ListView.separated`（itemBuilder + itemCount）已支持，闭包抽为组件方法由宿主还原原生构造 |
| **GridView** | `children`、`gridDelegate`、`scrollDirection`、`padding`、`shrinkWrap`、`physics`、`controller` | 四种形态：普通构造 / `GridView.builder`（itemBuilder + itemCount，同 ListView.builder 机制）/ `GridView.count(crossAxisCount:)` / `GridView.extent(maxCrossAxisExtent:)`（便捷参数进 props） |
| **ReorderableListView** | `children`、`onReorder`、`scrollDirection`、`padding`、`shrinkWrap`、`physics` | 拖拽排序列表；children 需各自带 `ValueKey`；`onReorder` 为 (oldIndex, newIndex) 双值事件 |
| **CustomScrollView** | `slivers`、`scrollDirection`、`physics`、`reverse`、`shrinkWrap`、`controller` | sliver 容器，`slivers` 列表进 children |
| **SliverList** | `delegate` 或 `.builder` / `.separated` | `delegate` 支持 `SliverChildListDelegate([...])`（children 展开）与 `SliverChildBuilderDelegate((c,i) => w, childCount: n)`（闭包抽方法）；`.builder` / `.separated`（itemBuilder + itemCount，+ separatorBuilder）同样闭包抽方法 |
| **SliverGrid** | `delegate`（同 SliverList）、`gridDelegate` | 支持 `.builder` 命名构造；gridDelegate 数值同 GridView |
| **SliverFixedExtentList** | `delegate`（同 SliverList）、`itemExtent`（必填） | 固定行高 sliver 列表 |
| **SliverFillViewport** | `delegate`、`viewportFraction` | 按视口分数分页的 sliver |
| **SliverAppBar** | AppBar 外观参数 + `pinned`、`floating`、`snap`、`expandedHeight` | 可滚动折叠的 AppBar；title/leading 为 element prop，actions 进 children |
| **SliverPadding** / **SliverToBoxAdapter** / **SliverFillRemaining** | `padding` / `child` | sliver 与盒子世界的互转与填充 |
| **SliverOpacity** / **SliverOffstage** / **SliverSafeArea** / **SliverIgnorePointer** / **SliverVisibility** | 与对应盒子版属性一致 | sliver 版可见性 / 安全区 / 拦截包装 |
| **Transform** | `offset`、`child` | 仅支持 `Transform.translate(offset: Offset(dx, dy))`；不支持 `Container.transform` 属性与 rotate/scale 工厂 |
| **EasyRefresh** | `child`、`onRefresh`、`onLoad`、`refreshOnStart` | 三方包 `easy_refresh` 的下拉刷新 / 上拉加载容器。`child` 为被包裹的滚动视图（element prop）；`onRefresh`/`onLoad` 是**可等待事件**（宿主触发 JS 方法、等其 Future 完成后才收起指示器，见 `capabilities/easy_refresh/`）；指示器样式（header/footer）与 `EasyRefreshController` 不参与翻译，统一用包内默认 Classic |

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **Text** | `data`、`style`、`maxLines`、`textScaler`、`overflow`、`textAlign`、`textDirection`、`softWrap`、`semanticsLabel` | `data` 支持状态插值；`textScaler` 支持 `TextScaler.noScaling` / `TextScaler.linear(n)`（新 API，废弃的 `textScaleFactor` 不支持）；`overflow` 支持 `TextOverflow.ellipsis/clip/fade/visible`；`textAlign` 支持 `TextAlign.left/right/center/justify/start/end`；`textDirection` 支持 `TextDirection.ltr/rtl`；`style` 见 §2.1 |
| **Icon** | `icon`、`size`、`color` | `icon` 需 `Icons.xxx`（运行时内置图标名映射）；`color` 见 §2.3 |

| **CircleAvatar** | `radius`、`minRadius`、`maxRadius`、`backgroundColor`、`foregroundColor`、`backgroundImage`、`child` | `backgroundImage` 支持 `AssetImage('x')` / `NetworkImage('url')`；`child` 可选 |
| **Chip** | `label`、`avatar`、`deleteIcon`、`onDeleted`、`backgroundColor`、`labelStyle`、`padding`、`side`、`shape`、`elevation` | `avatar`/`deleteIcon` 为 element prop；`shape` 见 §3.8 |
| **ListTile** | `title`、`subtitle`、`leading`、`trailing`、`onTap`、`onLongPress`、`tileColor`、`iconColor`、`textColor`、`contentPadding`、`dense`、`shape` | `title`/`subtitle` 需为 `Text`；`leading`/`trailing` 走通用翻译；事件见 §4 |
| **ClipRRect** | `borderRadius`、`clipBehavior`、`child` | `borderRadius` 支持 `BorderRadius.circular(n)` / `BorderRadius.all(Radius.circular(n))` |
| **ClipOval** | `clipBehavior`、`child` | 椭圆裁剪 |
| **Material** | `color`、`elevation`、`child` | 底纹/阴影容器（浮层阴影场景） |
| **Container** | `width`、`height`、`color`、`padding`、`margin`、`alignment`、`decoration`、`constraints`、`clipBehavior`、`child` | `decoration` 见 §2.4；color 与 decoration 同传时运行时按 Flutter 断言规则以 decoration 优先；无 decoration 时 `clipBehavior` 强制 Clip.none |
| **DecoratedBox** | `decoration`、`child` | `decoration` 见 §2.4（必填） |
| **Divider** | `height`、`thickness`、`indent`、`endIndent`、`color` | 数值需字面量 |
| **Card** | `child`、`elevation`、`margin`、`color`、`shape`、`clipBehavior`、`shadowColor` | `shape` 见 §3.8 |

### 1.7 响应式

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **ListenableBuilder** | `listenable`、`builder` | `listenable` 需为模型状态字段（如 `_model`，ChangeNotifier 子类）；`builder` 闭包返回的子树抽为组件方法，运行时做「仅此节点」局部重建（不全量 setState） |
| **ValueListenableBuilder** | `valueListenable`、`builder` | `valueListenable` 需为 `ValueNotifier` 状态字段；闭包形参 `(context, value)` 注册为局部变量，子树原样引用 |
| **Builder** | `builder` | 多一层 context 作用域，闭包内 `context.watch<T>()` / `context.read<T>()` 可用（调用面与 Dart 完全一致） |
| **ChangeNotifierProvider** | `create`、`child`（或 `.value(value:, child:)`） | provider 包（产物落 `patch/provider.js`）；需类型参数 `ChangeNotifierProvider<MyModel>`；`create` 为模型类引用（provider 持有生命周期）或状态字段实例（归调用方）；`.value` 复用既有实例不释放 |
| **MultiProvider** | `providers`、`child` | `providers` 为 `ChangeNotifierProvider` 列表（条目需类型参数，保持平级数组；运行时登记进 provider 栈，Consumer 按最近取值） |
| **Consumer** | `builder` | 需类型参数 `Consumer<MyModel>`；闭包形参 `(context, value[, child])`，value 注册为局部变量；模型变更时局部重建 |

### 1.8 自定义组件（嵌套 / 第三方）

| 场景 | 行为 |
|---|---|
| `@PatchEntry` 组件内部使用**其他注解组件** | 生成 JS import + 运行时递归加载（Component 节点 + import 相对路径） |
| `@PatchEntry` 组件 build 内使用**私有组件**（`_LabeledDivider` 等） | 依赖分析自动纳入翻译，生成 JS |
| 非注解组件（如业务注入的 `LabeledDivider`） | 运行时经全局 `registerNativeComponent` 注册的原生实现渲染，或由 JS 侧 import 覆盖（JS 优先） |
| 未注册组件 | 产物保留 Component 兜底节点；运行时无 import 且未注入 → 占位提示 |

### 2.3 颜色协议（所有 color 参数通用）

| 写法 | 产物 | 运行时 |
|---|---|---|

| `Color.fromARGB(a, r, g, b)` | `'#AARRGGBB'` | 直接构造 |

| `shape` | `BoxShape.circle / rectangle` |
| `image` | `DecorationImage(image: AssetImage/NetworkImage(...), fit:)` |

## 3. 通用值协议

### 3.1 EdgeInsets（padding / margin / contentPadding）

支持 `EdgeInsets.all(n)`、`EdgeInsets.symmetric(horizontal:, vertical:)`、`EdgeInsets.only(left:, top:, right:, bottom:)`、`EdgeInsets.fromLTRB(l, t, r, b)` → JSON `{left, top, right, bottom}`。

### 3.2 Alignment

`Alignment.center / topLeft / topCenter / topRight / centerLeft / centerRight / bottomLeft / bottomCenter / bottomRight`。

### 3.3 枚举写法

枚举属性一律写**静态引用**：`TextOverflow.ellipsis`、`TextAlign.center`、`MainAxisSize.max`、`BoxFit.cover` 等；不支持 `enum.toString()` 之类的运行时写法。

### 3.4 数字 / 布尔

数字属性（width/height/flex/spacing/elevation/radius 等）当前支持**字面量**（int/double）；绑定状态字段的场景（如 `Switch.value`、`Slider.value`）单独走状态字段协议。布尔属性（`enableFeedback`、`softWrap`）支持字面量。

### 3.5 ClipBehavior（clipBehavior 参数通用）

`Clip.none / hardEdge / antiAlias / antiAliasWithSaveLayer`。

### 3.6 BoxConstraints（Container.constraints / ConstrainedBox.constraints）

`BoxConstraints(minWidth:, maxWidth:, minHeight:, maxHeight:)` / `BoxConstraints.tightFor(width:, height:)` / `BoxConstraints.expand(...)`；值需数字字面量。

### 3.7 ScrollPhysics（physics 参数通用）

`NeverScrollableScrollPhysics()` / `AlwaysScrollableScrollPhysics()` / `BouncingScrollPhysics()` / `ClampingScrollPhysics()` → 类名字符串。

### 3.8 形状协议（ButtonStyle.shape / Card.shape / Chip.shape / ListTile.shape）

`RoundedRectangleBorder(borderRadius:, side:)` / `StadiumBorder(side:)` / `CircleBorder(side:)` / `BeveledRectangleBorder(...)` / `ContinuousRectangleBorder(...)` → JSON `{kind, borderRadius?, side?}`。

### 3.9 TextInputType（TextField.keyboardType）

`TextInputType.text / number / phone / emailAddress / url / multiline / datetime / visiblePassword` 等静态引用。

## 4. 事件协议

| 事件参数 | 支持写法 | 说明 |
|---|---|---|
| `onPressed` / `onTap` / `onLongPress` / `onDoubleTap` / `onDeleted` | `_method`（方法 tear-off）或 `() => _method()` / `() { _method(); }` | 方法名一一对应翻译到 JS；`onPressed: null` → 禁用态 |
| `onChanged`（Switch/Checkbox/Slider/TextField/Radio/DropdownButton） | 同上 | 带值事件，新值回传 JS 方法 |
| `onTap`（BottomNavigationBar） | 同上 | 带值事件，index 回传 JS 方法 |

**约束**：事件参数必须**直接引用组件方法**，不支持内联闭包体逻辑（如 `onTap: () { setState(...) }` 内联改写）。需要逻辑请写在组件方法里。

---

## 5. 通用翻译能力（build 内）

- **状态字段**：`_count` 类字段直接引用（`this._count`），属性一一对应
- **方法**：组件方法一比一翻译为 JS 方法
- **控制流**：`if`、`for`（含 `List.generate` 等价展开）、三目运算符
- **局部变量**：`build()` 内 `var x = ...;` 在 return 前声明（如 `var isAdult = user.age > 18;`），JS 侧同样先声明再 return
- **模型类**：lib 下 model（如 `User`）经依赖调用链分析自动纳入翻译（未被引用的模型不翻译）；产物 `import` + `export class`，跨文件复用
- **生命周期**：`initState` / `dispose` 等若在组件内实现，运行时在 JS 组件对应生命周期调用

---

## 6. 已知限制（后续补齐方向）

1. **数字属性**目前主要支持字面量与状态字段；运算表达式（`width: a + b`）需要进一步扩展
2. **废弃 API 一律不支持**（技术调研只做新 API）：如 `Text.textScaleFactor`（用 `TextScaler`）、`MaterialStatePropertyAll`（用 `WidgetStatePropertyAll`）；未来 Flutter 废弃的 API 同样不再投入支持
3. **Button child** 限定为纯字符串 Text；图标+文字组合（`Row(Icon, Text)`）暂不支持
4. **Image** 支持 asset/network 静态路径，不支持 `Image.memory` / 动态字节
5. **事件**不支持内联闭包逻辑改写（见 §4 约束）
6. **命令式 API 不做**：`showDialog` / `AlertDialog` / `SnackBar` 等命令式弹出不走声明式产物协议
7. **暂不支持**：`RadioGroup`（Flutter 3.32+ 成组 API；旧 `Radio` 仍可用）、`Container.transform` 属性（用 `Transform.translate` 代替）、`Transform.rotate/scale` 工厂
8. **Positioned 其它工厂**：`Positioned.directional`（需 textDirection）、`Positioned.fromRect` / `fromRelativeRect`（需 Rect 翻译）暂不支持
9. **组件清单会持续扩充**：新增组件 = 生成器加 Translator + 运行时加 Renderer（两侧各自独立文件，核心翻译/渲染代码零改动）

## 7. JS 引擎能力基线

热更产物跑在 `flutter_js`（^0.8.7）接入的 JS 引擎里：iOS 侧为 JavaScriptCore、Android 侧为 QuickJS。写补丁代码 / 评估某个 Dart 写法能否翻译时，以本节为基线。

### 7.1 语法面

| 层 | 语法基线 | 说明 |
|---|---|---|
| 生成器产物 | `class`（含 `get` 访问器）、`import` / `export`、`async` / `await` | 即 ES2015 module + ES2017 async 子集；产物由生成器统一产出，手写补丁对齐同一形态 |
| JS 运行时本体（`runtime_source.dart`） | ES5（`var` / `function`，无箭头函数、无 class） | 运行时按最保守语法书写，保证任何引擎版本可 eval |

### 7.2 内建 API 补齐（`runtime_source.dart`【1c】节）

产物里调用的方法名在原生 JS 对应类型上不存在时，一律在运行时给**内建原型**补同名同义方法（项目规则：禁止在生成器按方法名映射、禁止改 Dart 单源绕开——生成器不带类型解析，同名方法必撞车，如 `clear` 既是 `List.clear()` 也是 `TextEditingController.clear()`）。

| 已补项 | 语义 |
|---|---|
| `Array.prototype.clear()` | Dart `List.clear()` 的原地清空（保持数组实例，`final` 列表也能清；返回 void） |

新增补齐项三条硬要求：①挂最具体的内建原型（禁止 `Object.prototype`）；②`Object.defineProperty` 且 `enumerable: false`（不污染 `for...in` / `Object.keys` / `JSON.stringify`）；③带存在性守卫（引擎自带时以自带为准、可重复注入）。

**已知缺口**：Dart `Map` 字面量在 JS 侧是普通对象（非 Map 实例），`Map.clear()` 无处可挂，需要时得按「字段类型是 Map」在翻译层分发；Dart `Set` 字面量翻成 `new Set([...])`，JS Set 自带 `clear()`，无需处理。

> 注意：`runtime_source.dart` 属运行时 Dart 代码，改动随 App 一起注入——热更 / 热重启不生效，必须完全重启 App。
