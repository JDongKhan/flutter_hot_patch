# UI Component 组件支持文档

> 本文档列出 `ui_component_generator`（生成器）当前支持的 Flutter 组件、属性与写法约束。
> 生成器把 `@UIComponent` 注解类（含 `build()` 树）翻译为 JS 产物；`hot_patch` 运行时把产物还原为真实 Flutter widget（原生 vs JS 热更共用同一套属性协议）。
>
> **对齐口径**：生成器侧 `packages/ui_component_generator/lib/builtin_translators.dart` + `style_translators.dart`；运行时侧 `packages/hot_patch/lib/src/json/flutter_from_json.dart` + `js_ui/js_widget_registry.dart`。两端对称，新增属性必须同时改两侧。

---

## 1. 组件支持矩阵

### 1.1 布局类

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **Column** / **Row** | `children`、`mainAxisSize`、`mainAxisAlignment`、`crossAxisAlignment` | 主轴枚举：`MainAxisSize.min/max`；`MainAxisAlignment.start/center/end/spaceBetween/spaceAround/spaceEvenly`；`CrossAxisAlignment.start/center/end/stretch/baseline` |
| **Expanded** / **Flexible** | `flex`、`child` | 仅用于 Row/Column 内；`flex` 需整数字面量 |
| **Spacer** | `flex` | Row/Column 内弹性空隙；`flex` 需整数字面量（默认 1） |
| **Center** | `child` | 单子 |
| **Padding** | `padding`、`child` | `padding` 支持 `EdgeInsets.all/symmetric/only/fromLTRB`，见 §3.1 |
| **Align** | `alignment`、`child` | `alignment` 支持 `Alignment.center/topLeft/topCenter/topRight/centerLeft/centerRight/bottomLeft/bottomCenter/bottomRight` |
| **Stack** | `children`、`alignment`、`fit`、`clipBehavior` | `fit` 支持 `StackFit.loose/expand/passthrough`；`clipBehavior` 见 §3.5 |
| **Positioned** | `left`、`top`、`right`、`bottom`、`width`、`height`、`child` | 仅用于 Stack 内；数值需字面量；支持 `Positioned.fill(...)`（四边默认全 0 撑满，显式参数可覆盖偏移） |
| **SizedBox** | `width`、`height`、`child` | 可带 child（如 `SizedBox(height:100, child: Stack(...))`） |
| **Wrap** | `children`、`spacing`、`runSpacing`、`direction`、`alignment`、`runAlignment`、`crossAxisAlignment` | `spacing`/`runSpacing` 需数字字面量；`direction` 为 `Axis.*`；`alignment`/`runAlignment` 为 `WrapAlignment.*`；`crossAxisAlignment` 为 `WrapCrossAlignment.*` |
| **SafeArea** | `child`、`left`、`top`、`right`、`bottom` | 四边开关为 bool 字面量（默认 true） |
| **Opacity** | `opacity`、`child` | `opacity` 需数字字面量 |
| **ConstrainedBox** | `constraints`、`child` | `constraints` 见 §3.6 BoxConstraints |
| **AspectRatio** | `aspectRatio`、`child` | `aspectRatio` 需数字字面量 |
| **FractionallySizedBox** | `widthFactor`、`heightFactor`、`alignment`、`child` | 因子需数字字面量 |
| **SingleChildScrollView** | `child`、`scrollDirection`、`padding`、`physics`、`reverse` | `scrollDirection` 支持 `Axis.horizontal/vertical`；`physics` 见 §3.7 |
| **ListView** | `children`、`scrollDirection`、`padding`、`shrinkWrap`、`physics`、`itemExtent` | 列表子项走通用翻译（含 for 循环展开）；`shrinkWrap` 未下发时运行时按 true 处理（兼容旧产物） |

### 1.2 内容类

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **Text** | `data`、`style`、`maxLines`、`textScaler`、`overflow`、`textAlign`、`textDirection`、`softWrap`、`semanticsLabel` | `data` 支持状态插值；`textScaler` 支持 `TextScaler.noScaling` / `TextScaler.linear(n)`（新 API，废弃的 `textScaleFactor` 不支持）；`overflow` 支持 `TextOverflow.ellipsis/clip/fade/visible`；`textAlign` 支持 `TextAlign.left/right/center/justify/start/end`；`textDirection` 支持 `TextDirection.ltr/rtl`；`style` 见 §2.1 |
| **Icon** | `icon`、`size`、`color` | `icon` 需 `Icons.xxx`（运行时内置图标名映射）；`color` 见 §2.3 |
| **Image** | `source`、`width`、`height`、`fit`、`color`、`colorBlendMode`、`alignment`、`repeat` | `source` 支持 `Image.asset('x')` / `Image.network('url')` / `AssetImage` / `NetworkImage`；`fit` 支持 `BoxFit.cover/contain/fill/fitWidth/fitHeight/scaleDown/none`；`repeat` 支持 `ImageRepeat.repeat/repeatX/repeatY/noRepeat` |
| **CircleAvatar** | `radius`、`minRadius`、`maxRadius`、`backgroundColor`、`foregroundColor`、`backgroundImage`、`child` | `backgroundImage` 支持 `AssetImage('x')` / `NetworkImage('url')`；`child` 可选 |
| **Chip** | `label`、`avatar`、`deleteIcon`、`onDeleted`、`backgroundColor`、`labelStyle`、`padding`、`side`、`shape`、`elevation` | `avatar`/`deleteIcon` 为 element prop；`shape` 见 §3.8 |
| **ListTile** | `title`、`subtitle`、`leading`、`trailing`、`onTap`、`onLongPress`、`tileColor`、`iconColor`、`textColor`、`contentPadding`、`dense`、`shape` | `title`/`subtitle` 需为 `Text`；`leading`/`trailing` 走通用翻译；事件见 §4 |
| **ClipRRect** | `borderRadius`、`clipBehavior`、`child` | `borderRadius` 支持 `BorderRadius.circular(n)` / `BorderRadius.all(Radius.circular(n))` |
| **Container** | `width`、`height`、`color`、`padding`、`margin`、`alignment`、`decoration`、`constraints`、`clipBehavior`、`child` | `decoration` 见 §2.4；color 与 decoration 同传时运行时按 Flutter 断言规则以 decoration 优先；无 decoration 时 `clipBehavior` 强制 Clip.none |
| **DecoratedBox** | `decoration`、`child` | `decoration` 见 §2.4（必填） |
| **Divider** | `height`、`thickness`、`indent`、`endIndent`、`color` | 数值需字面量 |
| **Card** | `child`、`elevation`、`margin`、`color`、`shape`、`clipBehavior`、`shadowColor` | `shape` 见 §3.8 |

### 1.3 按钮类

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **ElevatedButton** / **TextButton** / **OutlinedButton** | `onPressed`、`child`、`style` | 三类产物统一为 `Button` 节点（`kind` 区分 elevated/text/outlined）；`child` 需为 `Text` 纯字符串；`onPressed: null` → 禁用态；`style` 见 §2.2 |
| **IconButton** | `icon`、`onPressed`、`color`、`iconSize`、`tooltip` | `icon` 为 element prop；`onPressed: null` → 禁用态 |
| **FloatingActionButton** | `child`、`onPressed`、`backgroundColor`、`foregroundColor`、`mini`、`tooltip`、`elevation` | `child` 为 element prop |

### 1.4 交互类

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **InkWell** | `onTap`、`onLongPress`、`onDoubleTap`、`borderRadius`、`splashColor`、`highlightColor`、`child` | 至少一个事件；事件见 §4 |
| **GestureDetector** | `onTap`、`onLongPress`、`onDoubleTap`、`behavior`、`child` | 同上；`behavior` 支持 `HitTestBehavior.deferToChild/opaque/translucent` |
| **Switch** | `value`、`onChanged`、`activeColor`、`activeTrackColor`、`inactiveThumbColor`、`inactiveTrackColor` | `value` 需为状态字段或字面量；`onChanged` 为带值事件；`activeColor` 运行时映射到 `activeThumbColor`（Flutter 3.31+ 改名） |
| **Checkbox** | `value`、`onChanged`、`activeColor`、`checkColor`、`tristate` | 带值事件；`tristate` 时 value 可为 null |
| **Slider** | `value`、`min`、`max`、`divisions`、`label`、`activeColor`、`inactiveColor`、`onChanged` | `min`/`max`/`divisions` 需数字字面量 |
| **TextField** | `onChanged`、`value`、`hintText`、`labelText`、`obscureText`、`enabled`、`keyboardType`、`maxLines`、`style`、`textAlign` | 受控协议：原生侧用 controller（JS 侧忽略）；`value` 下发时运行时为受控模式（props 变化回写 controller），不下发为非受控；`hintText`/`labelText` 支持顶层直传或 `decoration: InputDecoration(...)`；`keyboardType` 见 §3.9 |
| **Radio** | `value`、`groupValue`、`onChanged`、`activeColor` | 带值事件；Flutter 3.32+ 标记废弃（RadioGroup 暂无 translator），旧 API 仍可用 |
| **DropdownButton** | `value`、`items`、`onChanged`、`hint`、`isExpanded` | `items` 为 `DropdownMenuItem` 列表；带值事件 |
| **DropdownMenuItem** | `value`、`child` | `child` 需为 `Text`（提取纯文案） |

### 1.5 页面骨架

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **Scaffold** | `appBar`、`body`、`backgroundColor`、`floatingActionButton`、`bottomNavigationBar` | appBar/body 进 children（children[0]=AppBar、children[1]=body）；FAB/底部导航为 element prop |
| **AppBar** | `title`、`leading`、`actions`、`backgroundColor`、`foregroundColor`、`elevation`、`toolbarHeight`、`centerTitle`、`titleTextStyle` | `title`/`leading` 为 element prop；`actions` 列表进 children |
| **BottomNavigationBar** | `items`、`currentIndex`、`onTap`、`selectedItemColor`、`unselectedItemColor` | `items` 为 `BottomNavigationBarItem` 列表（进 children）；`onTap` 为带 index 值事件 |
| **BottomNavigationBarItem** | `icon`、`label` | `icon` 为 element prop；非 Widget，运行时由 BottomNavigationBar 收集还原 |

### 1.6 指示器

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **CircularProgressIndicator** | `value`、`color`、`backgroundColor`、`strokeWidth` | `value` 为 null 时无限旋转 |
| **LinearProgressIndicator** | `value`、`color`、`backgroundColor`、`minHeight` | 同上 |

### 1.7 响应式

| 组件 | 支持属性 | 说明 / 限制 |
|---|---|---|
| **ListenableBuilder** | `listenable`、`builder` | `listenable` 需为模型状态字段（如 `_model`，ChangeNotifier 子类）；`builder` 闭包返回的子树抽为组件方法，运行时做「仅此节点」局部重建（不全量 setState） |

### 1.8 自定义组件（嵌套 / 第三方）

| 场景 | 行为 |
|---|---|
| `@UIComponent` 组件内部使用**其他注解组件** | 生成 JS import + 运行时递归加载（Component 节点 + import 相对路径） |
| `@UIComponent` 组件 build 内使用**私有组件**（`_LabeledDivider` 等） | 依赖分析自动纳入翻译，生成 JS |
| 非注解组件（如业务注入的 `LabeledDivider`） | 运行时经 `nativeComponents` 注入，或由 JS 侧 import 覆盖（JS 优先） |
| 未注册组件 | 产物保留 Component 兜底节点；运行时无 import 且未注入 → 占位提示 |

## 2. 样式协议（JSON 属性详解）

### 2.1 TextStyle（`Text.style`、`ButtonStyle.textStyle`、`AppBar.titleTextStyle`、`Chip.labelStyle`）

| 属性 | 支持写法 |
|---|---|
| `fontSize` / `letterSpacing` / `wordSpacing` / `height` / `decorationThickness` | 数字字面量 |
| `fontWeight` | `FontWeight.bold/normal/w100…w900` |
| `fontStyle` | `FontStyle.italic/normal` |
| `color` / `backgroundColor` / `decorationColor` | 见 §2.3 颜色协议 |
| `fontFamily` / `fontFamilyFallback` | 字符串 / 字符串列表 |
| `decoration` | `TextDecoration.none/underline/overline/lineThrough` |
| `decorationStyle` | `TextDecorationStyle.solid/double/dotted/dashed/wavy` |

### 2.2 ButtonStyle（`ElevatedButton.styleFrom(...)` / `ButtonStyle(...)`）

| 属性 | 支持写法 |
|---|---|
| `backgroundColor` / `foregroundColor` / `overlayColor` / `iconColor` / `shadowColor` | 颜色协议；前四个自动解包 `WidgetStatePropertyAll` / `MaterialStatePropertyAll` |
| `disabledBackgroundColor` / `disabledForegroundColor` | 颜色协议；运行时合并进 background/foreground 的 `WidgetStateProperty.resolveWith`（ButtonStyle 无此参数，是 styleFrom 的便捷项） |
| `elevation` | 数字字面量 |
| `padding` | `EdgeInsets`（§3.1） |
| `minimumSize` / `maximumSize` / `fixedSize` | `Size(w, h)` |
| `side` | `BorderSide(color, width, style)` |
| `shape` | 见 §3.8 形状协议 |
| `textStyle` | 完整 TextStyle（§2.1） |
| `alignment` | `Alignment.*`（§1.1 Align 同表） |
| `visualDensity` | `VisualDensity.standard/compact/comfortable/adaptivePlatformDensity` |
| `enableFeedback` | `true / false` |

### 2.3 颜色协议（所有 color 参数通用）

| 写法 | 产物 | 运行时 |
|---|---|---|
| `Color(0xFFRRGGBB)` / `Color(0xAARRGGBB)` | `'#RRGGBB'` / `'#AARRGGBB'` | 直接构造 |
| `Color.fromARGB(a, r, g, b)` | `'#AARRGGBB'` | 直接构造 |
| `Colors.red / blue / teal …`（19 主色 + black/white） | `'#RRGGBB'` | 直接构造 |
| `Colors.blue.shade100 … shade900` | `'@Colors.blue.shade100'` 标记 | Flutter 官方 `Colors.*.shade*` 常量解析（值永不漂移） |
| 跨文件静态单例类字段（如 `PanelColors.background`） | 原样 JS 表达式 | JS 侧解析 |
| 三目（`isAdult ? A : B`） | JS 三目表达式 | JS 侧解析 |

### 2.4 BoxDecoration（`Container.decoration` / `DecoratedBox.decoration`）

| 属性 | 支持写法 |
|---|---|
| `color` | 颜色协议（§2.3） |
| `borderRadius` | `BorderRadius.circular(n)` / `BorderRadius.all(Radius.circular(n))` / `BorderRadius.only(topLeft: Radius.circular(n), ...)` 四角独立 |
| `border` | `Border.all(color:, width:, style:)` / `Border.fromBorderSide(BorderSide(...))` / `Border(top:, right:, bottom:, left:)` 四边独立 |
| `boxShadow` | `[BoxShadow(color:, offset: Offset(dx, dy), blurRadius:, spreadRadius:, blurStyle:)]` |
| `gradient` | `LinearGradient(colors:, begin:, end:, stops:)` / `RadialGradient(colors:, center:, radius:, stops:)` / `SweepGradient(colors:, ...)`；JSON 用 `kind` 键区分（避开 jsLiteral 对 `type` 键的 widget 节点拦截） |
| `shape` | `BoxShape.circle / rectangle` |
| `image` | `DecorationImage(image: AssetImage/NetworkImage(...), fit:)` |

## 3. 通用值协议

### 3.1 EdgeInsets（padding / margin / contentPadding）

支持 `EdgeInsets.all(n)`、`EdgeInsets.symmetric(horizontal:, vertical:)`、`EdgeInsets.only(left:, top:, right:, bottom:)`、`EdgeInsets.fromLTRB(l, t, r, b)` → JSON `{left, top, right, bottom}`。

### 3.2 Alignment

`Alignment.center / topLeft / topCenter / topRight / centerLeft / centerRight / bottomLeft / bottomCenter / bottomRight`。

### 3.3 枚举写法

枚举属性一律写**静态引用**：`TextOverflow.ellipsis`、`TextAlign.center`、`MainAxisSize.max`、`BoxFit.cover` 等；不支持 `enum.toString()` 之类的运行时写法。

### 3.4 数字 / 布尔

数字属性（width/height/flex/spacing/elevation/radius 等）当前支持**字面量**（int/double）；绑定状态字段的场景（如 `Switch.value`、`Slider.value`）单独走状态字段协议。布尔属性（`enableFeedback`、`softWrap`）支持字面量。

### 3.5 ClipBehavior（clipBehavior 参数通用）

`Clip.none / hardEdge / antiAlias / antiAliasWithSaveLayer`。

### 3.6 BoxConstraints（Container.constraints / ConstrainedBox.constraints）

`BoxConstraints(minWidth:, maxWidth:, minHeight:, maxHeight:)` / `BoxConstraints.tightFor(width:, height:)` / `BoxConstraints.expand(...)`；值需数字字面量。

### 3.7 ScrollPhysics（physics 参数通用）

`NeverScrollableScrollPhysics()` / `AlwaysScrollableScrollPhysics()` / `BouncingScrollPhysics()` / `ClampingScrollPhysics()` → 类名字符串。

### 3.8 形状协议（ButtonStyle.shape / Card.shape / Chip.shape / ListTile.shape）

`RoundedRectangleBorder(borderRadius:, side:)` / `StadiumBorder(side:)` / `CircleBorder(side:)` / `BeveledRectangleBorder(...)` / `ContinuousRectangleBorder(...)` → JSON `{kind, borderRadius?, side?}`。

### 3.9 TextInputType（TextField.keyboardType）

`TextInputType.text / number / phone / emailAddress / url / multiline / datetime / visiblePassword` 等静态引用。

## 4. 事件协议

| 事件参数 | 支持写法 | 说明 |
|---|---|---|
| `onPressed` / `onTap` / `onLongPress` / `onDoubleTap` / `onDeleted` | `_method`（方法 tear-off）或 `() => _method()` / `() { _method(); }` | 方法名一一对应翻译到 JS；`onPressed: null` → 禁用态 |
| `onChanged`（Switch/Checkbox/Slider/TextField/Radio/DropdownButton） | 同上 | 带值事件，新值回传 JS 方法 |
| `onTap`（BottomNavigationBar） | 同上 | 带值事件，index 回传 JS 方法 |

**约束**：事件参数必须**直接引用组件方法**，不支持内联闭包体逻辑（如 `onTap: () { setState(...) }` 内联改写）。需要逻辑请写在组件方法里。

## 5. 通用翻译能力（build 内）

- **状态字段**：`_count` 类字段直接引用（`this._count`），属性一一对应，无需 `@UIProp` 标注
- **方法**：组件方法一比一翻译为 JS 方法，无需 `@UIAction` 标注
- **控制流**：`if`、`for`（含 `List.generate` 等价展开）、三目运算符
- **局部变量**：`build()` 内 `var x = ...;` 在 return 前声明（如 `var isAdult = user.age > 18;`），JS 侧同样先声明再 return
- **模型类**：lib 下 model（如 `User`）经依赖调用链分析自动纳入翻译（未被引用的模型不翻译）；产物 `import` + `export class`，跨文件复用
- **生命周期**：`initState` / `dispose` 等若在组件内实现，运行时在 JS 组件对应生命周期调用

## 6. 已知限制（后续补齐方向）

1. **数字属性**目前主要支持字面量与状态字段；运算表达式（`width: a + b`）需要进一步扩展
2. **废弃 API 一律不支持**（技术调研只做新 API）：如 `Text.textScaleFactor`（用 `TextScaler`）、`MaterialStatePropertyAll`（用 `WidgetStatePropertyAll`）；未来 Flutter 废弃的 API 同样不再投入支持
3. **Button child** 限定为纯字符串 Text；图标+文字组合（`Row(Icon, Text)`）暂不支持
4. **ListView** 暂无 `itemBuilder`（builder 模式）；`Separated` 等变体待补
5. **Image** 支持 asset/network 静态路径，不支持 `Image.memory` / 动态字节
6. **事件**不支持内联闭包逻辑改写（见 §4 约束）
7. **命令式 API 不做**：`showDialog` / `AlertDialog` / `SnackBar` 等命令式弹出不走声明式产物协议
8. **暂不支持**：`TabBar` / `TabBarView` / `Drawer` / `GridView` / `PageView` / `Container.transform` / `RadioGroup`
9. **Positioned 其它工厂**：`Positioned.directional`（需 textDirection）、`Positioned.fromRect` / `fromRelativeRect`（需 Rect 翻译）暂不支持
10. **组件清单会持续扩充**：新增组件 = 生成器加 Translator + 运行时加 Renderer（两侧各自独立文件，核心翻译/渲染代码零改动）
