01 / BASICS

基础语法

声明、运算符、级联与表达式。多数与 JS 同形；级联和 `~/` 是例外。

01

变量与常量

直译

final 是只读引用，const 是编译期常量；const 构造 / 集合按站点缓存。

DART
final name = 'Ada';
const limit = 100;
var count = 0;

count = count + 1;
JAVASCRIPT
let name = "Ada";
const limit = 100;
let count = 0;

count = count + 1;
02

字符串插值

直译

插值表达式按同一套表达式翻译；相邻字符串字面量会拼接。

DART
final user = 'Ada';
final msg = 'Hi, $user (${user.length})';
JAVASCRIPT
let user = "Ada";
let msg = "Hi, " + user + " (" + user.length + ")";
03

算术与整除

注意

~/ 展开为 Math.trunc；% 在正数下同义，负数取模由运行时的 __mod 承接。

DART
final q = 7 ~/ 2;
final r = 7 % 2;
final area = width * height;
JAVASCRIPT
let q = Math.trunc(7 / 2);
let r = 7 % 2;
let area = width * height;
04

级联

必须改写

返回 target 的 IIFE；target 只求值一次，空安全级联在入口加非空守卫。

DART
final paint = Paint()
  ..color = Colors.red
  ..strokeWidth = 2;
JAVASCRIPT
const paint = ((_t) => {
  _t.color = Colors.red;
  _t.strokeWidth = 2;
  return _t;
})(new Paint());
05

三目、?? 与逻辑运算

注意

同形；?? 与其它运算组合时重建括号；逻辑运算的返回值按 JS 口径。

DART
final label = isAdult ? 'adult' : 'minor';
final name = user?.name ?? 'guest';
final ok = a > 0 && b > 0;
JAVASCRIPT
let label = isAdult ? "adult" : "minor";
let name = (user?.name) ?? "guest";
let ok = a > 0 && b > 0;
02 / TYPES & NULL SAFETY

类型与空安全

类型判定、可选链、空安全赋值、模式匹配与 Record。

01

is / is!

必须改写

按 typeTestJs 分派：String 用 typeof，List 用 Array.isArray，自定义类用 instanceof。

DART
if (value is String) {
  print(value.length);
}
final isList = value is List<int>;
JAVASCRIPT
if (typeof value === "string") {
  console.log(value.length);
}
const isList = Array.isArray(value);
02

as 类型断言

直译

as 在 JS 侧擦除（含类型参数）；需要运行时校验请显式写 is。

DART
final text = value as String;
final list = value as List<int>;
JAVASCRIPT
const text = value;
const list = value;
03

空安全读取

直译

JS 原生可选链；接收者只求值一次，null / undefined 时整链短路。

DART
final city = user?.address?.city;
final first = list?[0];
final name = user?.getName();
JAVASCRIPT
let city = user?.address?.city;
let first = list?.[0];
let name = user?.getName();
04

空安全赋值

必须改写

JS 可选链不能作赋值目标；落成接收者单次求值的守卫 IIFE，为空时整条赋值跳过。

DART
user?.name = 'Ada';
list?[0] = item;
JAVASCRIPT
((_t) => { if (_t != null) _t.name = "Ada"; })(user);
((_t) => { if (_t != null) _t[0] = item; })(list);
05

??= 与链式赋值

注意

??= 原样发射；赋值作为表达式时，值语义为赋值结果。

DART
count ??= 0;
name ??= 'guest';
final next = count += 1;
JAVASCRIPT
count ??= 0;
name ??= "guest";
const next = (count += 1);
06

模式匹配

扩展

if-case / switch guard 单次求值；绑定只在命中分支可见。

DART
if (value case User(:name) when name.isNotEmpty) {
  print(name);
}
JAVASCRIPT
if (value instanceof User && value.name != null && value.name.length > 0) {
  const name = value.name;
  console.log(name);
}
07

Record

必须改写

位置字段 $1..$N、命名字段原名；Record 的结构相等不伪造。

DART
final point = (1, 'a');
final named = (x: 1, y: 2);

print(point.$1);
print(named.x);
JAVASCRIPT
const point = { "$1": 1, "$2": "a" };
const named = { x: 1, y: 2 };

console.log(point.$1);
console.log(named.x);
03 / CONTROL FLOW

控制流

if / for / switch / label；差异集中在 switch 的隐式 break 与表达式形态。

01

if / while / for

直译

基本结构同形；for 的三段式原样发射。

DART
for (var i = 0; i < 3; i++) {
  print(i);
}
while (ready) {
  tick();
}
JAVASCRIPT
for (let i = 0; i < 3; i++) {
  console.log(i);
}
while (ready) {
  tick();
}
02

for-in

直译

Dart 的 in → JS 的 of；遍历依赖 [Symbol.iterator]。

DART
for (final item in items) {
  print(item.name);
}
JAVASCRIPT
for (const item of items) {
  console.log(item.name);
}
03

switch 自动 break

必须改写

Dart 3 隐式 break；翻译器在每个 case 末尾补 break，避免 JS 穿透。

DART
switch (status) {
  case Status.ok:
    print('ok');
  case Status.error:
    print('error');
  default:
    print('unknown');
}
JAVASCRIPT
switch (status) {
  case Status.ok:
    console.log("ok");
    break;
  case Status.error:
    console.log("error");
    break;
  default:
    console.log("unknown");
}
04

switch 表达式

必须改写

落成 IIFE 内的原生 switch 或 if 链；模式条件写成 switch (true)。

DART
final label = switch (code) {
  200 => 'ok',
  >= 400 && < 500 => 'client',
  _ => 'other',
};
JAVASCRIPT
const label = (() => {
  switch (true) {
    case code === 200: return "ok";
    case code >= 400 && code < 500: return "client";
    default: return "other";
  }
})();
05

label 与 break / continue

直译

Dart 标签在循环前，JS 标签在语句前；一比一发射。

DART
outer:
for (final row in rows) {
  for (final cell in row) {
    if (cell == null) continue outer;
    print(cell);
  }
}
JAVASCRIPT
outer:
for (const row of rows) {
  for (const cell of row) {
    if (cell == null) continue outer;
    console.log(cell);
  }
}
06

switch 模式与 guard

必须改写

含非常量模式或 when 的 switch 落成 switch (true) + 条件 IIFE；保持源码顺序、空 case 贯穿与 break / continue 语义。

DART
switch (value) {
  case User(:name) when name != '':
    print(name);
  case [int a, int b] when a < b:
    print(a + b);
  default:
    print('other');
}
JAVASCRIPT
switch (true) {
  case (() => {
    if (!(value instanceof User)) return false;
    const name = value.name;
    return name != "";
  })():
    console.log(value.name);
    break;
  case (() => {
    if (!Array.isArray(value) || value.length !== 2) return false;
    return Number.isInteger(value[0]) && Number.isInteger(value[1]) && value[0] < value[1];
  })():
    console.log(value[0] + value[1]);
    break;
  default:
    console.log("other");
}
04 / COLLECTIONS

集合与迭代

List / Map / Set / Iterable；名字映射只对可判定的内建接收者生效。

01

List 字面量与下标

注意

List → Array；add 等方法由 Array.prototype 补齐；越界行为接受差异。

DART
final list = <int>[1, 2, 3];
list.add(4);
final first = list[0];
JAVASCRIPT
const list = [1, 2, 3];
list.add(4);
const first = list[0];
02

List 高阶 API

扩展

map → _map；sort / join / indexOf 等按名字映射表改名；where 返回惰性 Iterable。

DART
final names = users.map((u) => u.name).toList();
final adults = users.where((u) => u.age >= 18);
final sorted = names..sort();
final joined = sorted.join(',');
JAVASCRIPT
const names = users._map((u) => u.name).toList();
const adults = users.where((u) => u.age >= 18); // LazyIterable
const sorted = names._sort();
const joined = sorted._join(",");
03

Iterable 惰性

扩展

where / expand / take / skip 返回 LazyIterable：调用时零副作用，消费时才迭代。

DART
final result = items
    .where((x) => x > 0)
    .map((x) => x * 2)
    .take(3)
    .toList();
JAVASCRIPT
const result = items
    .where((x) => x > 0)
    ._map((x) => x * 2)
    .take(3)
    .toList();
04

Map 字面量与下标

必须改写

Map 字面量 → 原生 Map；下标按接收者类型改写为 __idx / __idxSet，未命中归一为 null。

DART
final scores = <String, int>{'math': 100};
scores['physics'] = 66;
final math = scores['math'];
final keys = scores.keys;
JAVASCRIPT
const scores = new Map([["math", 100]]);
__idxSet(scores, "physics", 66);
const math = __nn(__idx(scores, "math"));
const keys = scores._keys;
05

Map 成员与 forEach

注意

keys / values / entries 改名为 _keys / _values / _entries；forEach 回调参数顺序在调用点交换。

DART
scores.forEach((k, v) => print('$k=$v'));
final found = scores.containsKey('math');
scores.remove('math');
JAVASCRIPT
scores.forEach((v, k) => console.log(k + "=" + v));
const found = scores.containsKey("math");
scores.remove("math");
06

Set

扩展

Set 字面量 → 原生 Set；Dart 同名成员按需在 Set.prototype 上补齐。

DART
final ids = <int>{1, 2, 3};
ids.add(4);
final has = ids.contains(1);
JAVASCRIPT
const ids = new Set([1, 2, 3]);
ids.add(4);
const has = ids.contains(1);
07

collection-if / for / spread

必须改写

条件元素 → 条件数组展开；collection-for → map 或立即执行的循环；...? 空安全展开为 []。

DART
final widgets = [
  const Header(),
  if (showBody) const Body(),
  for (final item in items) Tile(item),
  ...extras,
];
JAVASCRIPT
const widgets = [
  new Header({}),
  ...(showBody ? [new Body({})] : []),
  ...(() => {
    const out = [];
    for (const item of items) out.push(new Tile({ item }));
    return out;
  })(),
  ...extras,
];
05 / FUNCTIONS

函数与闭包

参数形态、泛型方法、tear-off、闭包与函数值调用。

01

位置参数 / 可选位置参数

注意

位置参数保留；可选位置缺省在函数体开头补默认值。

DART
int add(int a, [int b = 1]) => a + b;
JAVASCRIPT
function add(a, b) {
  if (b === undefined) b = 1;
  return a + b;
}
02

具名参数与默认值

必须改写

调用点把具名实参合并成尾参对象；定义侧用 __o 接住并解构。

DART
void greet({required String name, String prefix = 'Hi'}) {
  print('$prefix, $name');
}

greet(name: 'Ada');
JAVASCRIPT
function greet(__o) {
  const { name, prefix = "Hi" } = __o || {};
  console.log(prefix + ", " + name);
}

greet({ name: "Ada" });
03

泛型方法

注意

类型参数擦除；类型实参与具名实参共用尾参对象 typeArguments。

DART
T first<T>(List<T> items) => items.first;

final x = first<int>([1, 2]);
JAVASCRIPT
function first(items, __ta) {
  const T = ((__ta && __ta.typeArguments) || {})["T"];
  return items.first;
}

const x = first([1, 2], { typeArguments: { T: "int" } });
04

tear-off

必须改写

Dart 的方法引用自带 this；JS 需要 bind，且接收者只求值一次。

DART
final handler = _onTap;
final reset = controller.reset;
JAVASCRIPT
const handler = this._onTap.bind(this);
const reset = controller.reset.bind(controller);
05

闭包与局部函数

扩展

闭包 / 局部函数落成箭头函数或 const f = ...；保留 this 捕获，可递归。

DART
int factorial(int n) {
  int f(int x) => x <= 1 ? 1 : x * f(x - 1);
  return f(n);
}
JAVASCRIPT
function factorial(n) {
  const f = (x) => x <= 1 ? 1 : x * f(x - 1);
  return f(n);
}
06

函数值调用

注意

(f)(args) 支持；具名实参合并成尾参对象，闭包实参走同一条闭包翻译。

DART
final result = (f)(1, 2);
final pick = (x) => x;
JAVASCRIPT
const result = f(1, 2);
const pick = (x) => x;
07

typedef / 函数类型

直译

类型层信息擦除，不生成运行时代码；参数与返回值都不进 JS。

DART
typedef Handler = void Function(String);

Handler? onTap;
JAVASCRIPT
// 类型擦除：不产出运行时代码
let onTap = null;
06 / CLASSES

类与对象

构造、命名构造、初始化列表、super、运算符重载、extension / mixin、枚举与泛型。

01

class 与构造

必须改写

所有构造统一收一个 args 对象；字段由 __applyProps 派生。

DART
class Point {
  final double x;
  final double y;

  Point(this.x, this.y);

  double get length => sqrt(x * x + y * y);
}
JAVASCRIPT
class Point {
  constructor(args) {
    this.__applyProps(args);
  }

  __applyProps(args) {
    this.x = args.x;
    this.y = args.y;
  }

  get length() {
    return Math.sqrt(this.x * this.x + this.y * this.y);
  }
}
02

命名构造与 factory

必须改写

命名构造 / factory 发射为同名静态方法；构造名只存在于调用形状。

DART
class Point {
  final double x;
  final double y;

  Point(this.x, this.y);
  Point.origin() : x = 0, y = 0;
  factory Point.fromJson(Map j) => Point(j['x'], j['y']);
}
JAVASCRIPT
class Point {
  constructor(args) { this.__applyProps(args); }

  static origin() { return new Point({}); }

  static fromJson(j) {
    return new Point({ x: __idx(j, "x"), y: __idx(j, "y") });
  }
}
03

初始化列表

注意

初始化列表在 super 之后按序写入；super(...) 实参由基类 super(args) 承接。

DART
class Rect {
  final double w;
  final double h;

  Rect(double size) : w = size, h = size;
}
JAVASCRIPT
class Rect {
  constructor(args) {

04

getter / setter / static

直译

get / set 原样发射；static 成员挂类本身；私有字段保留下划线。

DART
class Counter {
  static int total = 0;
  int _value = 0;

  int get value => _value;
  set value(int v) => _value = v;

  static void reset() => total = 0;
}
JAVASCRIPT
class Counter {
  static total = 0;
  constructor() { this._value = 0; }

  get value() { return this._value; }
  set value(v) { this._value = v; }

  static reset() { Counter.total = 0; }
}

super 成员

注意

DART

  @override

JAVASCRIPT

06

运算符重载

扩展

按 __op$<后缀> 成员发射；只有操作数静态类型可判定时才改写调用点。

DART
class Vec {
  final int x;
  Vec(this.x);

  Vec operator +(Vec o) => Vec(x + o.x);
  Vec operator -() => Vec(-x);
  bool operator ==(Object o) => o is Vec && o.x == x;
}
JAVASCRIPT
class Vec {
  constructor(args) { this.x = args.x; }

  __op$add(o) { return new Vec({ x: this.x + o.x }); }
  __op$neg() { return new Vec({ x: -this.x }); }
  __op$eq(o) { return o instanceof Vec && o.x === this.x; }
}

10

接口与抽象类

直译

interface / abstract 只存在于类型层；JS 侧不生成 implements / abstract 标记。

DART
abstract class Shape {
  double area();
}

class Circle implements Shape {
  final double r;
  Circle(this.r);

  @override

JAVASCRIPT
class Circle {

11

泛型类

注意

类型参数擦除；构造时把元信息存进 __ta，方法里的 T 读 this.__ta["T"]。

DART
class Box<T> {
  final T value;
  Box(this.value);

  T get() => value;
}

final b = Box<int>(1);
JAVASCRIPT
class Box {
  constructor(args) {
    this.__ta = (args && args.typeArguments) || {};

const b = new Box({ value: 1, typeArguments: { T: "int" } });
07 / ERRORS & ASYNC

异常与异步

try / catch、throw 表达式、Future、Completer、Stream、生成器与 Timer。

01

try / on / catch / finally

必须改写

JS 只有单一 catch；Dart 的 on Type 落成 instanceof 链。

DART
try {
  risky();
} on StateError catch (e) {
  print('state: $e');
} on ArgumentError {
  print('arg');
} catch (e) {
  print(e);
} finally {
  cleanup();
}
JAVASCRIPT
try {
  risky();
} catch (__e) {
  if (__e instanceof StateError) {
    const e = __e;
    console.log("state: " + e);
  } else if (__e instanceof ArgumentError) {
    console.log("arg");
  } else {
    const e = __e;
    console.log(e);
  }
} finally {
  cleanup();
}
02

throw 表达式

必须改写

JS 没有 throw 表达式；落成立即抛出的 IIFE。

DART
final name = value ?? (throw StateError('missing'));
JAVASCRIPT
const name = value ?? (() => {
  throw new StateError({ message: "missing" });
})();
03

assert

扩展

assert 原样调用；函数本体由运行时注入，debug 门控。

DART
assert(count >= 0, 'count must be >= 0');
JAVASCRIPT
assert(count >= 0, "count must be >= 0");
04

async / await

直译

原生 async function / await；底层 Promise。

DART
Future<String> load() async {
  final data = await fetch();
  return data.name;
}

async* / yield

必须改写

async* 包成 Stream.fromAsyncGenerator；不能返回裸 async generator。

DART

  for (var i = 0; i < 3; i++) {
    yield i;
  }
}
JAVASCRIPT

  return Stream.fromAsyncGenerator((async function* () {
    for (let i = 0; i < 3; i++) {
      yield i;
    }
  }).bind(this)());
}
